# Video-Processing
This is a PyQt based desktop application built from the ground up, that uses the ONNX Runtime to run Deep Learning models on videos and live camera feeds. ONNX models are converted from Ultralytics. 
The long term goal of this project is to allow quick testing of Deep Learning Vision based models on real-world videos datasets.
